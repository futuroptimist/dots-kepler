# dots-kepler

A public experiment in versioned working agreements between a person and an AI assistant. This repository explores how to make reusable collaboration conventions transparent, reviewable, and easier to improve.

## How we work

Chat is where we discuss goals, clarify scope, and make decisions. A kanban board makes the work visible: cards describe outcomes, priorities, status, evidence, and next steps. The assistant researches and prepares work within the agreed scope, verifies results, and brings decisions back to the person.

We plan to evolve these conventions through pull requests, with examples and checks to make changes easier to review. An approved version can then be selected for adoption and verified in a fresh task.

## Relationship to Axel

[Axel](https://github.com/futuroptimist/axel) is a related project exploring agent-assisted work. Its existing synthetic, read-only board demo is a starting point; broader kanban functionality and live integrations are future work.

## Privacy and safety

This public repository is intended for reusable conventions, not private conversations, personal context, credentials, or secrets. We plan to add privacy and secret-scanning checks, alongside human review. Automated checks cannot guarantee that every sensitive detail is caught.

Repository guidance does not grant permissions or override current user instructions, platform safeguards, or access controls. This is an early-stage project; automatic loading across assistant sessions is not yet established.
